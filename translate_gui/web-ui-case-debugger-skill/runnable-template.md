# 可运行用例模板

文件为 **Markdown（.md）**，供执行 Agent（web-ui-case-executor）直接逐行执行。核心结构：**操作与预期分离**。

- **操作** = 命令式（点/填/等待），执行 Agent 必须逐条照做。
- **预期** = 校验式（确认 XX 出现 / 变为可用 / 显示值），逐条验证，不符仅记录。

## 层级规范（压平，不用 H1/H2）

```
H3  ### <用例名称>（可运行版）
H4  #### 执行约定 / #### 步骤N <阶段标题>
粗体标签  **操作** / **预期**   ← 不用 H 标题，也不用表格
列表  操作用「1. 2. 3.」，预期用「- [ ]」
```

示例：

```
### <用例名称>（可运行版）

- 测试目的：<一句话验证目标>
- 起始 URL：<起始地址>

#### 执行约定

- <补全的必填值，如密码>
- <分支处理，如登录后弹窗>
- <动态值处理，如按名称前缀匹配数据集>
- <不可自动化交互的等价操作，如时间范围用输入框填值>
- <动态指标只校验展示>

#### 步骤1 <阶段标题>

**操作**
1. <命令式：点击「XX」按钮 / 在「XX」输入框输入「值」 / 等待 XX 出现>
2. ...

**预期**
- [ ] <校验式：XX 出现 / XX 变为可用 / XX 显示值>
- [ ] ...
```

## 每步写法要求

- 「操作」：给出元素文本 / 占位符 / 按钮角色 + 交互动作，不依赖视觉坐标。
- 「预期」：校验出现 / 消失 / 可用状态等稳定结构，不绑定动态数值。
- 长任务写明：「点击『XX』→ 主动等待，轮询直到『XX』出现（最长 300 秒，每 10 秒一次）」。
- 同一步骤内可交替出现「**操作**」与「**预期**」块（操作后紧跟其预期）。
