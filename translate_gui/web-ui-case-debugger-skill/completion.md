# 调试结束标准

一次调试轮次结束后，对照下述两条标准判定是否结束。**两条必须同时满足**才可判定「调试结束，进入执行阶段」。

## 标准一：用户零介入

从本轮「初始化解析」到「全部步骤执行完」，用户**完全未介入**，包括：

- 未补充信息（如密码值）
- 未纠正步骤/预期
- 未在选项间做选择
- 未要求调整内容

只要用户在调试过程中说过话、给过结论、改过方向，本轮即不满足标准一。

## 标准二：直接按步骤描述执行

本轮执行过程中，所有操作都是**直接依据可运行用例的步骤描述**完成的，不存在：

- 试错（同一操作多次尝试才成功）
- 学习（借助上一轮调试的记忆/结论来补全本轮操作依据）
- 停下询问（执行中出现过需要澄清的点）

## 判定结果

| 标准一 | 标准二 | 判定 |
|--------|--------|------|
| 满足 | 满足 | **调试结束**，移交执行阶段（web-ui-case-executor 按最终可运行用例跑） |
| 任一不满足 | — | **继续下一轮调试**：回到流程②，用更新后的可运行用例重跑 |

## 结束时的产出

- 最终可运行用例文件（如 `demo1_exec.md`）
- 调试记录：每轮的用户介入点与改写内容，作为审计依据
- 移交说明：确认最终用例已满足两条标准
